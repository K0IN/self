# Black Forest Labs/FLUX.3 Image Klein 5.6B

- **Original model:** [black-forest-labs/flux-3-image-klein](https://huggingface.co/black-forest-labs/flux-3-image-klein)
- **License:** [FLUX Kommunity License](https://huggingface.co/black-forest-labs/flux-3-image-klein/blob/main/LICENSE.md). Review its non-commercial terms and qualifying-user commercial-output exception before use.
- **Quantization:** [Abiray/flux-3-image-klein-sd-GGUF](https://huggingface.co/Abiray/flux-3-image-klein-sd-GGUF), distilled Q4_K_M checkpoint.

FLUX.3 Image Klein combines text-to-image generation and reference-image editing.
The 5.6B parameter count describes the diffusion transformer, not the separate
Qwen3-VL-4B text encoder. This entry is the sixteen-step distilled model, not
Klein Base or the optional prompt upsampler.

## Usage

Build the updated image engine with `just engine image cpu` (or the matching
CUDA variant), then serve `flux3-klein:5.6b` with `self serve flux3-klein:5.6b`.
Existing installed `sd-server` binaries must be rebuilt: the old
`master-929-3f8527a` engine does not implement FLUX.3.

Generation and editing use the existing OpenAI-compatible image endpoints.
Defaults are 16 Euler steps, CFG 1.0, flash attention and CPU offloading.
Upstream supplies the model-specific time shift. Although the model supports
up to ten reference images, this server caps edits at eight.

## Runtime and Validation

Experimental integration using upstream stable-diffusion.cpp
[PR #2143](https://github.com/leejet/stable-diffusion.cpp/pull/2143), pinned to
`6d6ff751882e80e8f3af0942c9d4eb4e07375b19`. The PR is not yet merged.
It implements FLUX.3 architecture detection, Qwen3-VL layer conditioning and
reference-image editing; FLUX.2 runtime support alone is insufficient.

The text encoder is used through `--llm`; this pipeline does not require the
Qwen vision projector used by Qwen Image 2.1. The VAE is shared with FLUX.2.
All files have immutable revision, byte-size and SHA-256 pins from Hugging Face
LFS metadata. The diffusion GGUF is a community conversion, not an official
BFL artifact. Original BFL repositories require license acceptance.

Actual weight loading, visual quality, CPU/CUDA inference and reference editing
have not been verified through `self`. Do not treat unit tests or an engine
build as an inference smoke test. No performance or quality benchmark is claimed.
