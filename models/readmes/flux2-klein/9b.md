# FLUX.2-klein 9B

FLUX.2-klein 9B is a distilled text-to-image and image-editing model that supports multi-reference editing. The stable-diffusion.cpp backend exposes it through an OpenAI-compatible server API.

Source: [Black Forest Labs FLUX.2-klein-9B](https://huggingface.co/black-forest-labs/FLUX.2-klein-9B).
GGUF diffusion weights: [unsloth/FLUX.2-klein-9B-GGUF](https://huggingface.co/unsloth/FLUX.2-klein-9B-GGUF).

The 9B weights are distributed under the FLUX Non-Commercial License. Review the upstream license and all usage restrictions before deployment.

## Registry status

Registered as `flux2-klein:9b` with a `q4` variant. It pins the Unsloth diffusion
Q4_K_M GGUF, Qwen3-8B Q4_K_M encoder and the FLUX.2 safetensors VAE from
Comfy-Org/flux2-klein. All artifacts have fixed revisions, sizes and SHA-256
pins. The image-only VAE role explicitly permits safetensors.

```bash
self serve flux2-klein:9b --registry models/registry.yml
```

This is the distilled 9B checkpoint, not the base or KV variant. Defaults use
four Euler steps, CFG 1 and flash attention. The official upstream `sd-server`
loads the pipeline once and handles generation and edits. See [Image API](/api/images).
Native model inference and GPU performance must still be verified on target hardware.

## Capabilities

- Text-to-image generation
- Single- and multi-reference image editing
- OpenAI-compatible `POST /v1/images/generations` and `POST /v1/images/edits` through stable-diffusion.cpp
