# Clef Flash 9B

[Cloudflare/clef-flash](https://huggingface.co/Cloudflare/clef-flash): a
Qwen3.5-9B multimodal backbone with a trained joint schema head. It reads the
state, optional images and every question in one pass and scores all options of
all questions together, for `choice`, `score` and `noul` questions.

- Engine: `clef` (llama.cpp backbone, native joint head, no Python)
- Files: Bartowski's Q4_K_M GGUF, the F16 vision projector and Cloudflare's
  `joint_head.safetensors`
- Up to 32 options per question, 16384 tokens of context (state, schema and
  images share it; a state that does not fit is truncated like upstream does)
- Vision: up to 4 images per request (`images`), read in the same pass
- The confidence of a `choice` is the probability of the chosen option

```bash
self serve clef-flash:9b
```

## Prompting with multiple images

Send up to 4 images in `images`. They are read in the order given and are not
named, so refer to them by position ("the first image") in `state` and in the
questions. All questions are answered together in one pass.

```bash
curl http://localhost:8080/v1/systemone \
  -H 'Content-Type: application/json' \
  -d '{
    "state": "Compare two delivery photos. The first image shows a parcel left on a doorstep, the second image shows a pallet of boxes in a warehouse.",
    "images": [
      "https://upload.wikimedia.org/wikipedia/commons/thumb/b/b7/Damaged_fragile_parcel_delivered_to_doorstep.jpg/1280px-Damaged_fragile_parcel_delivered_to_doorstep.jpg",
      "https://upload.wikimedia.org/wikipedia/commons/thumb/9/9e/Nestle_kolileri_palette_01.jpg/1280px-Nestle_kolileri_palette_01.jpg"
    ],
    "questions": {
      "more_damaged": {
        "type": "choice",
        "instructions": "Which image shows the more damaged goods?",
        "criteria": {
          "first": "The first image",
          "second": "The second image"
        }
      },
      "second_intact": {
        "type": "noul",
        "instructions": "Are all boxes in the second image intact?"
      }
    }
  }'
```

```json
{
  "model": "clef-flash:9b",
  "answers": {
    "more_damaged": {
      "type": "choice",
      "choice": "first",
      "probabilities": { "first": 0.8982, "second": 0.1018 },
      "confidence": 0.8982
    },
    "second_intact": { "type": "noul", "noul": 0.9146, "confidence": 0.9146 }
  },
  "usage": { "input_tokens": 2532, "output_tokens": 0, "images": 2, "latency_ms": 1111.2 }
}
```

Images can also be JPEG, PNG or WebP data URIs.
