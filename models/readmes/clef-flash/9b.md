# Clef Flash 9B

[Cloudflare/Clef Flash](https://huggingface.co/Cloudflare/clef-flash) is a
multimodal decision model based on Qwen3.5-9B, released under Apache-2.0.
Its upstream System One API produces choice, score, and noul answers using
a custom joint schema head over the backbone's hidden states.

## GGUF Files

The registry entry `clef-flash:9b` pins the Q4_K_M backbone and F16 vision
projector from
[Bartowski's conversion](https://huggingface.co/bartowski/Cloudflare_clef-flash-GGUF).
The backbone is 5,841,052,992 bytes; the projector is 918,165,984 bytes.
Both downloads are protected by SHA-256 pins in the registry.

## Runtime Status

This entry registers a placeholder adapter named `ggmlc-clef`. Native
inference is not implemented, and no Clef engine binary is bundled.
The model is listed for integration work, not as a currently usable model.

The registry uses the upstream record encoder's default 16,384-token limit.
The 10-option limit is provisional for this integration entry, not an
upstream Clef model limit.

The GGUF conversion contains the backbone and vision projector, but not
the required upstream `joint_head.safetensors` and its configuration.
Completing native GGUF inference requires converting and loading that head,
reproducing the upstream record encoding, and computing per-option logits
from the backbone's hidden states. The existing `ggmlc-custom-decider`
adapter reads vocabulary letter logits and must not be used as a substitute.
