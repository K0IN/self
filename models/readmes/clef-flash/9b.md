# Cloudflare/Clef Flash 9B

- **License:** [Apache-2.0](https://huggingface.co/Cloudflare/clef-flash/blob/main/LICENSE)
- **Release date:** [2026-10-01](https://blog.cloudflare.com/clef-decision-models/) (public announcement)
- **Modalities:** Input: text, images; Output: typed decisions (`choice`, `score`, `noul`)
- **Original model:** [Cloudflare/clef-flash](https://huggingface.co/Cloudflare/clef-flash)

## Description

Clef Flash combines a Qwen3.5-9B multimodal backbone with a trained joint schema
head. It reads a state and typed questions together, scoring every allowed
option in a single forward pass instead of generating free-form text.

## Run

```bash
self serve clef-flash:9b
```

Here is a link to the API docs: [Decision API](/api/decision).

### Example Request

With the server running, open another terminal and send a request:

```bash
curl http://localhost:8080/v1/systemone \
  -H 'Content-Type: application/json' \
  -d '{
    "state": "Checkout is failing and customers cannot place orders.",
    "questions": {
      "department": {
        "type": "choice",
        "instructions": "Which team should handle this ticket?",
        "criteria": {
          "billing": "Payments and refunds",
          "technical": "Bugs and outages"
        }
      }
    }
  }'
```

The server returns a JSON decision for the `department` question.

## Engine Parameters

Served by the native `clef` engine through the `clef` adapter.

| Parameter | Default | What it controls |
| --- | --- | --- |
| `context_size` | `16384` | Token budget shared by state, schema and images; accepts 512 to 262144. |
| `threads` | Hardware concurrency (at least `1`) | CPU workers; accepts 1 to 1024. |
| `gpu_layers` | `-1` | GPU-offloaded backbone layers; `-1` means all, `0` means CPU; accepts -1 to 10000. CPU device selection forces zero offload. |

Override startup settings with `--set <parameter>=<value>`.

## Notes

- Up to 32 options per question and 4 images per request. Images share the default 16384-token context with the state and schema; an oversized state is truncated.
- Send images in the `images` array as URLs or JPEG, PNG or WebP data URIs. Refer to them by position ("the first image"); all questions are answered together.
- The confidence of a `choice` is the probability of the chosen option. No free-form text generation or video-input API is exposed here, even though upstream supports video.
- The backbone, vision projector and joint head are all required. Download size is not the total runtime memory requirement.
- Origin links use `main` because these registry entries pin hashes, not repository revisions.
