# Clef Flash 9B

[Cloudflare/clef-flash](https://huggingface.co/Cloudflare/clef-flash): a
Qwen3.5-9B multimodal backbone with a trained joint schema head. It reads the
state, optional images and every question in one pass and scores all options of
all questions together, for `choice`, `score` and `noul` questions.

- Engine: `clef` (llama.cpp backbone, native joint head, no Python)
- Files: Bartowski's Q4_K_M GGUF, the F16 vision projector and Cloudflare's
  `joint_head.safetensors`
- Up to 32 options per question, 16384 tokens of context (state, schema and
  images share it; a state that does not fit is truncated like upstream does)
- Vision: up to 4 images per request (`images`), read in the same pass
- The confidence of a `choice` is the probability of the chosen option

```bash
self serve clef-flash:9b
```
