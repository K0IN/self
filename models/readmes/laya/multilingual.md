# Laya Multilingual

Encoder-based System One decision model (mmBERT encoder, multilingual), compiled with
[ggmlc](https://github.com/monatis/ggmlc). Very fast `choice`, `score` and
`noul` answers for text.

- Engine: upstream `laya` daemon (`ggmlc-laya` adapter)
- Up to 16 options per question
- Text only

```bash
self serve laya:multilingual
```
