## Description

Nomic Embed Text v1.5 converts English text into vectors for retrieval,
clustering, and classification. Its Matryoshka training allows smaller
representations to trade some accuracy for reduced storage. The upstream
model supports sequences up to 8192 tokens and full 768-dimensional vectors.

## Run

```bash
self serve nomic-embed-text-v1.5:137m
```

Here is a link to the API docs: [Embeddings API](/api/embeddings).

### Example Request

With the server running, open another terminal and send a request:

```bash
curl http://localhost:8080/v1/embeddings \
	-H 'Content-Type: application/json' \
	-d '{"input":"search_query: What is semantic search?"}'
```

The server returns a JSON response containing the embedding vector.

## Engine Parameters

Served by the upstream `llama-server` through the embedding adapter. These
are startup settings, not per-request API fields. Settings not specified in
the registry are left to the bundled engine's defaults.

| Parameter | Default | What it controls |
| --- | --- | --- |
| `context_size` | `8192` | Engine context size in tokens; accepts integers from 512 to 1048576. The adapter range is not a guarantee of model support. |
| `pooling` | `mean` | Embedding pooling; accepts `none`, `mean`, `cls`, `last`, or `rank`. Keep `mean` for this model's sentence embeddings. |
| `threads` | Engine default (not set in registry) | Number of CPU workers; accepts integers from 1 to 1024. |
| `gpu_layers` | Engine default (not set in registry) | Layers offloaded to GPU; accepts integers from -1 to 10000, with -1 meaning all layers. |
| `flash_attn` | Engine default (not set in registry) | Flash Attention mode: `auto`, `on`, or `off`; availability depends on the backend and model. |
| `parallel` | Engine default (not set in registry) | Number of parallel engine slots; accepts integers from 1 to 256. |

Override startup settings with `--set <parameter>=<value>`.

## Notes

- Task prefixes are required: use `search_query: ` for retrieval queries and `search_document: ` for indexed documents. For other tasks, use `clustering: ` or `classification: ` as documented upstream. Include the prefix in every input string; the adapter does not add it.
- The API returns full vectors and does not support the `dimensions` request field. For downstream Matryoshka reduction, follow the upstream procedure: layer-normalize the full vector, truncate to the desired dimension, then L2-normalize. Process queries and documents consistently.
- Download size is not the total runtime memory requirement.
- The origin link uses `main` because the registry pins the file hash, not a repository revision.
