# Qwen/Qwen-Image-2.1-Turbo 7B

- **License:** [Qwen Research License Agreement](https://huggingface.co/Qwen/Qwen-Image-2.1-Turbo/blob/main/LICENSE)
- **Modalities:** Input: text, image, multiple images; Output: image
- **Original model:** [Qwen/Qwen-Image-2.1-Turbo](https://huggingface.co/Qwen/Qwen-Image-2.1-Turbo)

## Description

Qwen-Image-2.1-Turbo accelerates the Qwen-Image-2.1 7B visual generation
architecture for eight-step text-to-image generation and reference-image
editing, including transparent images. The separate text encoder is not
included in the 7B parameter count.

## Run

```bash
self serve qwen-image-2.1-turbo:7b
```

See the [Image API](/api/images) for generation and editing requests.

### Example Request

```bash
curl http://localhost:8080/v1/images/generations \
        -H 'Content-Type: application/json' \
        -d '{"prompt":"A red bicycle leaning against a white wall","size":"1024x1024","n":1,"output_format":"png"}' \
        -o response.json
jq -r '.data[0].b64_json' response.json | base64 --decode > output.png
```

## Engine Parameters

| Parameter | Default | What it controls |
| --- | --- | --- |
| `steps` | `8` | Number of denoising steps. |
| `sigmas` | `1.0,0.978453,0.95418,0.926626,0.89508,0.845148,0.704534,0.414568,0.0` | Published Turbo schedule with terminal zero. |
| `cfg_scale` | `1.0` | Guidance scale. |
| `sampling_method` | `euler` | Sampling method. |
| `flash_attention` | `true` | Enable flash attention. |
| `offload_to_cpu` | `true` | Offload inactive model stages to CPU. |

Override startup settings with `--set <parameter>=<value>`. Per-request
sampling overrides are documented in the Image API.

## Notes

Both quantizations require the Qwen Image 2.1 BF16 VAE, Qwen3-VL-8B-Instruct
text encoder and F16 vision projector listed in the generated registry details.
The API accepts at most eight reference images. Use dimensions divisible by 32
and PNG output to preserve transparency.

The checkpoint-specific eight-step sigma schedule is passed to sd-server with
`--sigmas`.

## Local Validation

On 2026-10-11, both registered Q4 and Q8 variants were downloaded through
`self pull` with the source registry and verified against its artifact pins.
Both started through `self serve --device cuda` on an NVIDIA RTX 5090 using
stable-diffusion.cpp `master-929-3f8527a` and the registry sampling defaults.

- Q4 and Q8: health returned HTTP 200; generation returned one valid 512x512
        PNG for "A simple bright red apple on a white background" (seed 7).
        Visual inspection confirmed the requested object, color and background.
- Q4: a single-reference edit changed the apple to green while preserving
        its shape, stem and composition, returning a valid 512x512 PNG.
- Q4: an empty generation prompt returned HTTP 400 `invalid_request`.

These are basic inference smoke tests. Q8 editing, multiple-reference edits,
transparent output, CPU execution and equivalence to the official Diffusers
pipeline remain unverified.
