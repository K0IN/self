# jaredpalmer/Kev 4B

- **License:** [Apache-2.0](https://www.apache.org/licenses/LICENSE-2.0)
- **Release date:** 2026-09-24 (Kev 1.0 checkpoint, as documented in the original model card)
- **Modalities:** Input: text; Output: typed decisions (`choice`, `score`, `noul`)
- **Original model:** [jaredpalmer/kev-4b](https://huggingface.co/jaredpalmer/kev-4b)

## Description

Kev reads a document (the state) and typed questions, returning calibrated
probabilities over the supplied options in one forward pass without generating
text. This model uses a LoRA adapter and a pointer head on Qwen3.5-4B-Base.
It is intended for document classification, routing, triage, and checks where
probability thresholds can direct uncertain cases to human review.

## Run

```bash
self serve kev:4b
```

Here is a link to the API docs: [Decision API](/api/decision).

### Example Request

With the server running, open another terminal and send a request:

```bash
curl http://localhost:8080/v1/systemone \
	-H 'Content-Type: application/json' \
	-d '{
		"state": "I was charged twice for the same order.",
		"questions": {
			"department": {
				"type": "choice",
				"instructions": "Which department should handle this support ticket?",
				"criteria": {
					"billing": "Payments and refunds",
					"technical": "Technical problems"
				}
			}
		}
	}'
```

The server returns a JSON decision for the `department` question.

## Engine Parameters

Served by the upstream `laya` daemon through the `ggmlc-laya` adapter.

| Parameter | Default | What it controls |
| --- | --- | --- |
| `threads` | `4` | Number of CPU workers; accepts integers from 1 to 1024. |
| `cuda_graph` | `true` for `auto` / CUDA devices; otherwise `false` | Capture a CUDA graph for the live request shape. |

Override startup settings with `--set <parameter>=<value>`.

## Notes

- Text only; up to 16 options per question.
- Context and option limits are compiled into the GGUF and cannot be changed at runtime.
- Download size is not the total runtime memory requirement.
- Origin links use `main` because these registry entries pin hashes, not repository revisions.
