# Kev 0.8b

System One decision model built on Qwen and compiled with
[ggmlc](https://github.com/monatis/ggmlc). Answers typed `choice`, `score`
and `noul` questions about a text `state` in a single forward pass.

- Engine: upstream `laya` daemon (`ggmlc-laya` adapter)
- Up to 16 options per question
- Text only

```bash
self serve kev:0.8b
```
