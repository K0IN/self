# Mapika/Decider Vision 2B

- **License:** [Apache-2.0](https://huggingface.co/Mapika/decider-2b-vision/blob/main/README.md)
- **Release date:** Not documented for the current weights; [2026-09-16](https://huggingface.co/api/models/Mapika/decider-2b-vision) is the first HF publication (repository creation), not a verified date for this revision.
- **Modalities:** Input: text, image; Output: typed decisions (`choice`, `score`, `noul`)
- **Original model:** [Mapika/decider-2b-vision](https://huggingface.co/Mapika/decider-2b-vision)

## Description

Decider Vision combines Decider 2B v5 language weights with the Qwen3.5-2B
vision-language model. It scores supplied options for questions about photos,
diagrams or game frames in one forward pass, without generating captions or
chat responses. Training combines visual multiple-choice tasks, game frames
and text replay, followed by PPO on Pong and Breakout.

## Run

```bash
self serve decider-vision:2b
```

Here is a link to the API docs: [Decision API](/api/decision).

### Example Request

With the server running, open another terminal and send a request:

```bash
curl http://localhost:8080/v1/systemone \
	-H 'Content-Type: application/json' \
	-d '{
		"state": "Inspect this photograph.",
		"images": ["https://upload.wikimedia.org/wikipedia/commons/3/3a/Cat03.jpg"],
		"questions": {
			"animal": {
				"type": "choice",
				"instructions": "Which animal is shown?",
				"criteria": {"cat": "A cat", "dog": "A dog"}
			}
		}
	}'
```

The server returns a JSON decision for the `animal` question.

## Engine Parameters

Served by the llama.cpp-based `ggmlc-custom-decider` engine and adapter.
These are startup settings, not per-request API fields.

| Parameter | Default | What it controls |
| --- | --- | --- |
| `context_size` | `8192` | Context tokens including prompt and image tokens; accepts integers from 512 to 262144. |
| `threads` | llama.cpp default | CPU workers; accepts integers from 1 to 1024. |
| `temperature` | `1.0` | Softmax temperature on option-letter logits, not text sampling; accepts 0.01 to 100. |
| `gpu_layers` | `-1` (all); `0` on CPU devices | Layers offloaded to the GPU; accepts integers from -1 to 10000. |
| `flash_attn` | `auto` | Flash attention mode: `auto`, `on`, or `off`. |
| `image_min_tokens` | Unset (projector metadata) | Minimum tokens per image; accepts integers from 1 to 65536. |
| `image_max_tokens` | Unset (projector metadata) | Maximum tokens per image; accepts integers from 1 to 65536. |

Override startup settings with `--set <parameter>=<value>`.

## Notes

- Up to 10 options per question; one image per request through `images`. Both weights and the Qwen-VL projector are required.
- Images must be public HTTPS URLs or JPEG, PNG, or WebP data URIs by default; HTTP and private addresses require explicit server opt-ins.
- English only; not a chat model or captioner. Text-only behavior comes from Decider 2B v5, not newer text releases.
- Upstream visual calibration and game results cover specific datasets, not your images; validate confidence on your own inputs.
- Download size is not the total runtime memory requirement.
- Origin links use `main` because these registry entries pin hashes, not repository revisions.
