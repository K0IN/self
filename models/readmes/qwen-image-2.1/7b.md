## Description

Qwen-Image-2.1 unifies text-to-image generation and reference-image editing,
including native transparent images, subject extraction and transparent-layer
editing. Its 7B visual generation component uses 32 Single-Stream DiT layers;
the parameter count does not include the separate text encoder. The model
focuses on typography, realistic textures and preserving people and products
across edits.

## Run

```bash
self serve qwen-image-2.1:7b
```

Here is a link to the API docs: [Image API](/api/images).

### Example Request

With the server running, open another terminal and send a request:

```bash
curl http://localhost:8080/v1/images/generations \
	-H 'Content-Type: application/json' \
	-d '{
		"prompt": "A red fox in a snowy forest",
		"size": "1024x1024",
		"n": 1,
		"output_format": "png"
	}' \
	-o response.json
```

The server returns JSON with base64-encoded image bytes in `data[0].b64_json`,
not a hosted image URL. Decode the first result with `jq` and `base64`:

```bash
jq -r '.data[0].b64_json' response.json | base64 --decode > output.png
```

## Engine Parameters

Served by the unmodified upstream stable-diffusion.cpp `sd-server` through the
`sd-server` adapter, with one loaded pipeline per process. These are startup
settings; defaults below come from the registry. Unset settings are delegated
to the engine rather than assigned a default by the adapter.

| Parameter | Default | What it controls |
| --- | --- | --- |
| `steps` | `40` | Sampling steps; accepts integers from 1 to 200. |
| `cfg_scale` | `6.0` | Guidance scale; accepts values from 0 to 50. |
| `sampling_method` | `euler` | Sampling method; the adapter accepts only `euler`. |
| `flash_attention` | `true` | Enable flash attention. |
| `offload_to_cpu` | `true` | Offload inactive model stages to CPU. |
| `threads` | Unset (engine default) | CPU workers; accepts integers from 1 to 1024. |
| `seed` | Unset (engine default) | Default seed; accepts integers from 0 to 9223372036854775807. |

Override startup settings with `--set <parameter>=<value>`.

Per-request fields such as `size`, `n` and `output_format` belong in the API
request, not `--set`; a request's `seed` overrides the startup seed. Backend
sampling overrides can be supplied through
`sd_cpp_extra_args.sample_params`; see the Image API for the backend-specific
request format. Omitting overrides keeps the startup sampling defaults.

## Notes

- The Qwen Research License is not Apache-2.0; review its restrictions before use, particularly for commercial deployments.
- The default official INT8 ConvRot pipeline pairs the Qwen3-VL-8B-Instruct Q4_K_M encoder with the model's BF16 VAE and F16 vision projector. The projector is required for edits; older Qwen Image VAEs cannot replace the 2.1 VAE.
- Upstream supports ten reference images, but this API caps editing at eight. See the Image API for multipart uploads and remote reference URLs.
- Use dimensions divisible by 32. Request transparent RGBA output in the prompt and select PNG to preserve alpha.
- CPU and CUDA builds use the same official server. CPU inference can be slow; total working memory exceeds downloaded weight sizes.
- Registration and mocked protocol tests are not an end-to-end inference benchmark. Validate generation and editing on target hardware.
