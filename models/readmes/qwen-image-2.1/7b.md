# Qwen-Image-2.1 7B

Unified image generation and multi-reference editing, served by the unmodified
official stable-diffusion.cpp `sd-server`, with one loaded pipeline per process.

Source: [Qwen/Qwen-Image-2.1](https://huggingface.co/Qwen/Qwen-Image-2.1).
Diffusion weights: [Comfy-Org](https://huggingface.co/Comfy-Org/Qwen-Image-2.1)
for the default official INT8 ConvRot pipeline, plus
[Unsloth GGUF](https://huggingface.co/unsloth/Qwen-Image-2.1-GGUF) variants.
License: **Qwen Research License**, not Apache-2.0. Review the upstream license
before use, particularly for commercial deployments.

The default `int8` variant matches the upstream stable-diffusion.cpp example:
the official INT8 ConvRot diffusion model with the Qwen3-VL-8B-Instruct Q4_K_M
GGUF text encoder, plus the model's own BF16 safetensors VAE and F16 GGUF
vision projector. The registry also offers `q8` and `q4` GGUF variants for
lower memory use. The projector is required for edits. Older Qwen Image VAEs
cannot replace the 2.1 VAE. Artifact revisions, byte sizes and SHA-256 values
are pinned in the registry.

```bash
self serve qwen-image-2.1:7b --registry models/registry.yml
```

Defaults use the official INT8 ConvRot pipeline, Euler sampling, CFG 6 and
flash attention. Sampling steps use the configured registry value unless
overridden with `--set steps=...`. Use dimensions divisible by 32. Request
transparent RGBA output in the prompt and select PNG to preserve alpha. The
API currently caps editing at eight reference images.

See [Image API](/api/images) for generation, uploads and remote reference URLs.
Both CPU and CUDA builds use the same official server. CPU inference can be
slow; total working memory exceeds the downloaded weight sizes.

Registration and mocked protocol tests do not constitute an end-to-end model
inference benchmark. Validate generation and editing on your target hardware.
