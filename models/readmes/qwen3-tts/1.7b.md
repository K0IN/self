# Qwen3-TTS 1.7B Base

Multilingual text-to-speech through the `ggmlc-audio` engine (llama.cpp's
Qwen3-TTS pipeline, model kept loaded between requests). This Base model
supports reference-audio voice cloning; it is not the CustomVoice or
VoiceDesign variant.

Source: [Qwen/Qwen3-TTS-12Hz-1.7B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base).
GGUF artifacts: [ggml-org/Qwen3-TTS-12Hz-1.7B-Base-GGUF](https://huggingface.co/ggml-org/Qwen3-TTS-12Hz-1.7B-Base-GGUF).
License: Apache-2.0.

Available variants are `q4` (default), `q8`, and `bf16`. Each downloads a
language model and matching audio projector. Sizes and SHA256 values are
pinned from upstream LFS metadata.

Build the engine with `just engine audio` (variant `cpu`, `vulkan`,
`cuda-12.8` or `cuda-13.4`), then serve with `self serve qwen3-tts:1.7b`.

Speech is exposed at `POST /v1/audio/speech` (OpenAI-compatible). Output is WAV
at 24 kHz; instruction-based voice design and non-default speed are not
implemented.

## Prompting and controls

Put the words you want spoken in `input`. For this Base model, `input` is
spoken content, not a chat prompt: commands such as "speak louder", "sound
angry", "whisper", or "use a warm tone" are not a supported instruction
channel. The server rejects a non-empty `instructions` field with
`422 unsupported_capability`, and `speed` values other than `1` are also
rejected by the current runtime.

Use the request fields that the model actually supports:

| Goal | Set | Notes |
| --- | --- | --- |
| Choose spoken language | `language` | Supported examples include `en`, `de`, `fr`, `es`, `it`, `pt`, `ru`, `ja`, `ko`, and `zh`. |
| Imitate a speaker | `ref_audio` or `voice.audio` | Send a clean 5-20 second MP3 or WAV reference with every request. |
| Use the model's built-in voice | Omit the reference audio | OpenAI voice names such as `alloy` are aliases for this same default voice. |
| Change speed | `speed` | The API validates `0.25`-`4`, but this model currently supports only `1`. |
| Change emotion, pitch, loudness, or speaking style | Not available | Use a different recording or post-process the generated WAV. |

The model can express punctuation and formatting that are present in the text,
but this should not be confused with reliable style control. For example,
writing `Hello...` may create a pause, but it does not provide a documented
way to request a specific emotion, pitch, or loudness.

### Default voice

```bash
curl http://localhost:8080/v1/audio/speech \
  -H 'Content-Type: application/json' \
  -d '{"input":"Welcome to the local speech model.","language":"en"}' \
  -o default.wav
```

### Reference voice

The reference recording conditions the speaker identity for that request. It
does not train the model or create a reusable server-side profile:

```bash
curl http://localhost:8080/v1/audio/speech \
  -F input='This sentence should sound like the reference speaker.' \
  -F language=en \
  -F ref_audio=@my-voice.mp3 \
  -o cloned.wav
```

### Multilingual speech

Set `language` explicitly when the text is not English or when you want to
avoid relying on language detection:

```bash
curl http://localhost:8080/v1/audio/speech \
  -H 'Content-Type: application/json' \
  -d '{"input":"Guten Morgen! Wie geht es dir heute?","language":"de"}' \
  -o german.wav
```

### Unsupported style request

This request does not make Qwen3-TTS speak louder. It returns an error because
instruction control is not exposed by the bundled Base runtime:

```bash
curl http://localhost:8080/v1/audio/speech \
  -H 'Content-Type: application/json' \
  -d '{"input":"Hello","instructions":"Speak louder and sound excited."}'
```

```json
{
  "error": {
    "type": "unsupported_capability",
    "message": "instructions are not supported by the loaded audio model"
  }
}
```

For instruction-based voice design or named speaker/style control, use a model
variant that supports those features. This registry entry is specifically the
Qwen3-TTS **Base** variant and currently exposes reference-audio cloning only.

## Voices

Without a reference recording the model speaks in its own default voice. OpenAI
voice names (`alloy`, ...) are accepted but select that same default voice.

To clone a voice, send a clean 5-20 second WAV or MP3 recording of one speaker
as `ref_audio` (multipart file) or as `voice.audio` (base64). Nothing is stored,
so send it with every request. Set `language` (`en`, `de`, `fr`, `es`, `it`,
`pt`, `ru`, `ja`, `ko`, `zh`) to choose the spoken language:

```bash
curl http://localhost:8080/v1/audio/speech \
  -F input='Guten Morgen! Wie geht es dir heute?' \
  -F language=de \
  -F ref_audio=@my-voice.mp3 \
  -o output.wav
```

Use only voices you own or have permission to use.

Measured on CPU (q4): engine ready in under 1 s with cached files, about 4 s
per short sentence, with or without a reference voice.
