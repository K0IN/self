# Qwen3-TTS 1.7B Base

Multilingual text-to-speech through the `ggmlc-audio` engine (llama.cpp's
Qwen3-TTS pipeline, model kept loaded between requests). This Base model
supports reference-audio voice cloning; it is not the CustomVoice or
VoiceDesign variant.

Source: [Qwen/Qwen3-TTS-12Hz-1.7B-Base](https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-Base).
GGUF artifacts: [ggml-org/Qwen3-TTS-12Hz-1.7B-Base-GGUF](https://huggingface.co/ggml-org/Qwen3-TTS-12Hz-1.7B-Base-GGUF).
License: Apache-2.0.

Available variants are `q4` (default), `q8`, and `bf16`. Each downloads a
language model and matching audio projector. Sizes and SHA256 values are
pinned from upstream LFS metadata.

Build the engine with `just engine audio` (variant `cpu`, `vulkan`,
`cuda-12.8` or `cuda-13.4`), then serve with `self serve qwen3-tts:1.7b`.

Speech is exposed at `POST /v1/audio/speech` (OpenAI-compatible). Output is WAV
at 24 kHz; instruction-based voice design and non-default speed are not
implemented.

## Voices

Without a reference recording the model speaks in its own default voice. OpenAI
voice names (`alloy`, ...) are accepted but select that same default voice.

To clone a voice, send a clean 5-20 second WAV or MP3 recording of one speaker
as `ref_audio` (multipart file) or as `voice.audio` (base64). Nothing is stored,
so send it with every request. Set `language` (`en`, `de`, `fr`, `es`, `it`,
`pt`, `ru`, `ja`, `ko`, `zh`) to choose the spoken language:

```bash
curl http://localhost:8080/v1/audio/speech \
  -F input='Guten Morgen! Wie geht es dir heute?' \
  -F language=de \
  -F ref_audio=@my-voice.mp3 \
  -o output.wav
```

Use only voices you own or have permission to use.

Measured on CPU (q4): engine ready in under 1 s with cached files, about 4 s
per short sentence, with or without a reference voice.
