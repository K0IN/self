# Nomic Embed v1.5

Nomic Embed v1.5 is an English text embedding model served through llama.cpp.

Source: [nomic-ai/nomic-embed-text-v1.5](https://huggingface.co/nomic-ai/nomic-embed-text-v1.5).
GGUF: [nomic-ai/nomic-embed-text-v1.5-GGUF](https://huggingface.co/nomic-ai/nomic-embed-text-v1.5-GGUF).
License: Apache-2.0.

```bash
self serve nomic:1.5
```

Use the model's task prefixes, such as `search_query:` and `search_document:`
when building retrieval indexes and queries.
