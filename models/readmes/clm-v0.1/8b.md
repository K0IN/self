# CLM v0.1 8B

CLM is a contrastive encoder based on Qwen3-8B. It produces last-token pooled
vectors for text ranking and retrieval through llama.cpp's embeddings API.

Source: [Contrastive-LM/CLM-v0.1-8B](https://huggingface.co/Contrastive-LM/CLM-v0.1-8B).
GGUF: [czl/CLM-v0.1-8B-GGUF](https://huggingface.co/czl/CLM-v0.1-8B-GGUF).
License: Apache-2.0.

```bash
self serve clm-v0.1:8b
```

The registry sets `pooling: last`, as required by the encoder. The model is
English-focused and is intended for ranking and embedding workflows.
