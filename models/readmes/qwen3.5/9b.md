# Qwen3.5 9B

Qwen's multilingual chat model (hybrid Gated DeltaNet / attention architecture,
262,144 token context). Served by upstream `llama-server` from llama.cpp, using
its own chat template, reasoning split and sampler, with the model kept loaded
between requests. The bundled projector enables text and image input.

Source: [Qwen/Qwen3.5-9B](https://huggingface.co/Qwen/Qwen3.5-9B).
GGUF artifacts: [unsloth/Qwen3.5-9B-GGUF](https://huggingface.co/unsloth/Qwen3.5-9B-GGUF).
License: Apache-2.0.

Available variants are `q4` (Q4_K_M, default) and `q8` (Q8_0). Each downloads
the language model and the F16 vision projector (`mmproj`). Sizes and SHA256
values are pinned from upstream LFS metadata.

```bash
self serve qwen3.5:9b
```

Text example:

```bash
curl http://localhost:8080/v1/chat/completions \
	-H 'Content-Type: application/json' \
	-d '{"model":"qwen3.5:9b","messages":[{"role":"user","content":"Say hello in one word."}],"reasoning_effort":"none","max_tokens":16}'
```

Image messages use the standard OpenAI `image_url` content part. The URL may
be HTTPS or a base64 data URL.

Chat at `POST /v1/chat/completions` (OpenAI-compatible). See [Text generation API](/api/text).

## Thinking

Qwen3.5 thinks before it answers by default; the thinking comes back as
`reasoning_content`, separate from `content`. Turn it off per request with
`"reasoning_effort": "none"` (or `"chat_template_kwargs": {"enable_thinking": false}`),
or for the whole server with `--set thinking=off`.

## Sampling

The registry carries the model card's settings for general thinking tasks:
`temperature` 1.0, `top_p` 0.95, `top_k` 20, `min_p` 0, `presence_penalty` 1.5.
A request's own `temperature`, `top_p` and `presence_penalty` win. The card
suggests `temperature` 0.7 and `top_p` 0.8 when thinking is off. The context
window is 16,384 tokens by default (`--set context_size=...`; the model supports
262,144).
